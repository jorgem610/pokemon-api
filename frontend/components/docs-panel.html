Documentación de la API

Endpoints REST para gestionar Pokémon y sus tipos elementales.

GET /pokemon/

Devuelve todos los Pokémon, incluyendo sus tipos.

GET /pokemon/{id}

Devuelve un Pokémon concreto por su id.

POST /pokemon/

Crea un Pokémon nuevo.

{
  "name": "Charizard",
  "level": 36,
  "hp": 78,
  "type_ids": [1, 2]
}
PUT /pokemon/{id}

Actualiza un Pokémon existente.

DELETE /pokemon/{id}

Elimina un Pokémon.

GET /types/

Devuelve todos los tipos.

POST /types/

Crea un tipo nuevo.

{ "name": "Fuego" }
PUT /types/{id}

Actualiza un tipo existente.

DELETE /types/{id}

Elimina un tipo.
